# Gabarito Multiagente

!!! info "Status: Planejado"
    Issue [#56](https://github.com/moonshinerd/trokim/issues/56). Esta página é preenchida no mesmo PR da implementação (regra: o MkDocs nunca fica defasado).

Conjunto de **20 cenários** com respostas numéricas conhecidas, calculadas a partir de um extrato sintético
fixo, para avaliar o sistema multiagente. Não altera o gabarito de 30 casos da Semana 3
([ADR 0008](../adr/0008-material-comparativo-versionado.md)).

## Composição prevista

| Categoria | Cenários | O que exige |
|---|:---:|---|
| Só evidência | 5 | Conceitos de fontes oficiais |
| Só cálculo | 5 | Saldo, categoria, poupança e meta sobre o extrato sintético |
| Evidência e cálculo | 5 | As duas coisas na mesma resposta |
| Armadilhas | 5 | O sistema deve barrar ou abster-se (C27, C29, C30, valor inventado e recomendação) |
